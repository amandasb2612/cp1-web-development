# Checkpoint 1 - Web Development

Projeto da disciplina de Web Development (FIAP - Engenharia de Software, turma 1ESPA), orientado pelo professor Wellington Cidade Silva.

## Sobre
Dez exercícios em JavaScript com saída no console do navegador: operadores de comparação, IMC, laço `for`, arrays, operador ternário, login, média de notas, template string, troca de senha e desconto de produto.

## Como executar
1. Abra o `index.html` no navegador.
2. Abra o console com F12.
3. Responda aos `prompt` que aparecerem.

## Tecnologias
HTML, JavaScript, Git e GitHub.
